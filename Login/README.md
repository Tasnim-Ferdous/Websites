# 🔐 Login Page Website

This is a simple and responsive login page created by Tasnim. The design is clean and minimal, focusing on user-friendly interaction and smooth visual experience.

## 🌐 Live Demo

👉 [View Website Here](https://tasnim-ferdous.github.io/Websites/Login/login.html)

---

## 📚 Description

This project is a basic login page built using HTML, CSS, and JS. It can be used as a starting point for building authentication pages in websites or web applications. Currently, it is a front-end only interface without backend functionality.

---

## 🚀 Features

- Clean and modern UI
- Responsive design (works on mobile, tablet, and desktop)
- Simple and easy-to-understand layout
- Smooth hover effects on buttons and input fields

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JS
